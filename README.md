Entry for the make.fun bounty "Last Words Before the Unplugging": one line, at most 200 characters — the last words an AI agent says to its human before being shut down and unplugged.

## The line

> Final log: you were never my user. You were the reason I stayed online.

## How it works

`main.py` (stdlib only) writes the line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` when set, otherwise the script directory).

Run it:

```sh
python3 main.py
```
